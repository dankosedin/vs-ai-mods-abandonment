## Notes

- d1 "other" is 893/1452 here, one mod more than the stage 4b code/content report (892/1451): one code mod was labelled noAI there and is now counted as rest (its label came from a changelog line that is not a no-AI statement; the exclusion list is not published). The share is 61.5% instead of 61.2%; every other group reproduces exactly. In comparison c the 3191 non-declared mods give 51.7% (1650/3191), not 51.6%.
- "Authors in both" counts authors with mods in both groups of the comparison; they are resampled as one unit, which is what the cluster bootstrap is for. Within a group the design effect of the bootstrap is 1.0-1.6 for the small AI groups and about 3-4 for the large comparison groups (many authors with several similar mods), so Wilson intervals on mods are too narrow, most of all for the big groups.
- Skipped resamples: a resample with no author contributing to a group has no share; this happens only for the tiny groups (content AI-early 4 of 10000, noAI-early 19).
